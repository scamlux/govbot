# GovBot: план апгрейдов (чек-лист)

Источник пунктов: `2026-10-27-features.md` (A–F) и `2026-10-27-redesign.md` (R1–R7).
Статусы: ⬜ не начато · 🔄 в работе · ✅ сделано (коммит + проверка) · ⛔ заблокировано (внешний блокер назван) · ⏭️ пропущено (причина).

Правила, которые действуют для всех пунктов:
- Миграции только аддитивные: новые поля nullable или с default, без переименований и удалений.
- Всё, что открывает неавторизованный доступ или тратит деньги (гостевой чат, Telegram, виджет), включается флагом в env и по умолчанию выключено.
- Данные не выдумываются: пошлины, сроки и URL услуг вносятся только из проверенных источников. Структура и UI делаются, контент заполняет редактор.
- Перед каждым пушем: backend pytest, `makemigrations --check`, frontend `npm test` и `npm run build`.
