# GovBot: исследование фич (срез на 2026-10-27)

Автор исследования: исследовательский агент, проверка кода и рынка. Выводы о проде сделаны по коду, сервер агент не запускал. Оценки усилий и ценности экспертные. Юридические формулировки требуют проверки юристом.

## 0. Итог

- Продукт технически зрелее, чем говорит роадмап: часть пунктов M2/M3 уже в коде. Главный пробел в содержании и доверии. Каталог тонкий, `source_url` указывает на главную страницу домена, видимого AI-дисклеймера нет.
- У my.gov.uz появился собственный «AI Assistant» [1]. Ниша GovBot: три языка простым языком, ответы через ведомства без OneID, туристы и иностранные резиденты.
- Приоритет: доверие и качество ответов, затем охват (гость, Telegram), затем операции.

## 1. Что проверено в коде (расхождения с документацией)

Подтверждено: маршруты `frontend/src/App.jsx`; 7 вкладок админки; SSE, source-чипы, 👍/👎, RelatedQuestions, голос, экспорт, офлайн-баннер; PWA `public/sw.js`; throttling.

Найдено сверх описания:

1. **C2, A3, C1/C3 уже в коде**, хотя роадмап держит их как будущие. Бэкенд: `AdminFeedbackListView`, `question_analytics`, `usage_analytics`, `catalog_gaps`. Фронт: в `Admin.jsx` есть `scenarioPrefill` и кнопка «создать сценарий» из пробела. Осталось улучшение: кластеризация по эмбеддингам вместо нормализации текста.
2. Документация устарела: «7 сценариев», а в `seed_scenarios.py` 35 сценариев в 7 категориях (в локальной БД после сидинга подтверждено: 7 и 35).
3. Модуль `knowledge` управляется только через Django admin, во фронтовой админке его нет.
4. Есть веб-фолбэк Tavily (`chat/search.py`), выключен по умолчанию (`KB_SEARCH_PROVIDER=none`). Домены по умолчанию `gov.uz,uz`, то есть любой `.uz`.
5. `source_url` в сидах это домен верхнего уровня (`my.gov.uz`, `soliq.uz`, `e-visa.gov.uz`), не страница услуги. `ScenarioDetail.jsx` `source_url` не показывает (подтверждено grep). Он виден только в чипах чата.
6. В `MessageBubble.jsx` у сценарных чипов внешняя ссылка всегда подписана «official source». У KB-чипа нет ярлыка происхождения, у web-чипа есть бейдж «live search». Различия «каталог / база знаний / веб» нет.
7. Видимого дисклеймера «не официальный совет» в i18n нет, хотя PRD §10 называет его митигацией.
8. Тела сценариев общие: «госпошлина (может отличаться)», без сумм, сроков и документов по случаям.
9. Офлайн-каталог, вероятно, не работает на Vercel: `sw.js` кэширует `/api/scenarios` только для своего origin, а API живёт на Render. Вывод из кода, на проде не проверено.
10. Безопасность (по grep): `token_blacklist` не найден при `ROTATE_REFRESH_TOKENS=True`, серверного logout, по-видимому, нет; у `MeView` нет DELETE; команд purge/retention диалогов нет; `CORS_ALLOWED_ORIGIN_REGEXES = ^https://[a-z0-9-]+\.vercel\.app$` вместе с `CORS_ALLOW_CREDENTIALS=True` станет риском после перехода на cookie (S2).
11. Harness оценки ретривала (B4): файлов `eval/golden/benchmark` нет.
12. Язык ответа задаётся полем `language` из UI, автоопределения языка сообщения нет.
13. `.github/workflows/deploy.yml` описывает SSH-деплой на сервер, README говорит про Vercel/Render.

## 2. Рынок: что подтверждено

| Сервис | Что делает | Урок для GovBot | Источник |
|---|---|---|---|
| GOV.UK Chat | Отвечает только по опубликованному на GOV.UK. Точность выросла с 76% до 90%. 508 попыток jailbreak отбиты. Уточняющие вопросы подняли долю in-scope до 88%. План передачи в поддержку ведомства | eval-набор, уточняющие вопросы, hand-off | [2] |
| GOV.UK Chat, дизайн | «Check this answer»: ссылки на страницы-источники. Онбординг с предупреждением о неточности. Пользователи переоценивали точность из-за бренда | Ссылки на источники и онбординг-дисклеймер | [3] |
| my.gov.uz | «AI Assistant», 905 услуг, контроль сроков документов и SMS/PUSH, раздел для иностранцев (e-visa, регистрация, линии 112/1173/1242) | Не дублировать уведомления; идти в понятность и кросс-ведомственность | [1][4][5][14] |
| my.gov.uz, правила AI | Ответы консультативные, официальные решения только по утверждённым документам. Приказ Минцифры №3787 от 14.03.2026 | Нужен видимый дисклеймер; применимость приказа к частному сервису неясна | [1] |
| Bürokratt (Эстония) | Сеть чат-ботов ведомств; неотвеченные чаты уходят операторам; голос; 18 организаций; план LLM+RAG | Hand-off к человеку, единая точка входа | [6][7][8] |
| Ask Jamie (Сингапур) | В 2021 Минздрав отключил бот после «misaligned» ответов | Guardrails и kill-switch | [9][10] |
| Госуслуги (РФ) | Бот в мессенджере MAX: уведомления о выплатах и статусах, оплата штрафов | Канал-мессенджер для статусов | [11] |

## 4. Приоритизация

### Топ-10

1. **A1** дисклеймер и онбординг (S): главный пробел доверия.
2. **A2** ярлыки источников и `source_url` на странице сценария (S).
3. **A3** канонический `source_url` и дата проверки (M).
4. **A6** «не знаю» вместо ответа из памяти модели (S).
5. **A4** eval-harness (M).
6. **B1** гостевой чат с квотами (M).
7. **C1** структурированные чек-листы и наполнение каталога (M).
8. **E1** ревью и аппрув сценариев (M).
9. **D1** Telegram-бот (M).
