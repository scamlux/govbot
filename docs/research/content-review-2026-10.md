# Обновление контента каталога сценариев — проверка редактором (2026-10)

## Что сделано

Команда `python manage.py apply_content_updates` (запускается при каждом деплое, повторный запуск ничего не меняет) заменяет общие ссылки-заглушки (`https://my.gov.uz`, `https://soliq.uz`, `https://e-visa.gov.uz`) на ссылки конкретных официальных страниц услуг и добавляет чек-листы документов там, где они были найдены в официальных источниках. Данные: `backend/scenarios/content/official_sources_2026_10.json`.

- Ссылка заменяется только если в карточке всё ещё стоит старая заглушка (или пусто). Всё, что менял редактор, не трогается.
- Чек-лист заполняется только если он пуст на всех трёх языках.
- Статус, публикация, заголовок, текст, теги, аудитория не меняются. Карточки остаются опубликованными.
- Поле «Проверено» (`verified_at`) остаётся пустым: его выставляет владелец после проверки.
- Перед каждым изменением создаётся запись в истории (заметка «content update 2026-10 (official sources)»).

**Откат:** админка → Сценарии → нужная карточка → История → выбрать запись с этой заметкой → Восстановить.

Переводы пунктов на uz/ru/en частично выполнены нами по официальным формулировкам (см. колонку «что проверить»); перед выставлением даты проверки сверьте их с источником.
