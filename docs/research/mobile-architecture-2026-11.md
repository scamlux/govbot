# GovBot mobile 2.0 — стек и карта функций (2026-11-11)

## Решение: React Native + Expo SDK 58 (нативный UI), сборка локально

| Критерий | Capacitor (v1, WebView) | **React Native / Expo 58** | Flutter |
|---|---|---|---|
| Анимации, жесты, blur | CSS в WebView, 60 fps не гарантирован | **Reanimated 4 на UI-потоке, Skia, нативный blur, 120 Гц** | отлично (Impeller) |
| Нативное ощущение | «сайт в обёртке», риск App Store 4.2 | **нативные навигация, листы, haptics** | отлично |
| Общее с вебом | весь код | **язык React, i18n-ключи, API-логика** | ничего (Dart) |
| Скорость разработки | максимальная | высокая (Expo Router, готовые модули) | средняя, второй стек |
| Сборка без облака | да | **да: `expo prebuild` + Gradle** | да |

v1 (Capacitor) остаётся как запасной вариант; v2 — отдельный проект `app/`.

Версии (npm, 2026-11-11): expo 58.0.23, react-native 0.88.1, expo-router 58, react-native-reanimated 4.7.1,
@shopify/react-native-skia 2.14.0, react-native-gesture-handler 3.5.0, expo-blur / expo-haptics /
expo-secure-store / expo-notifications / expo-speech 58, @tanstack/react-query 5.107, i18next 27.

## Архитектура

- **Навигация:** Expo Router, нижние вкладки «Bosh · Suhbat · Katalog · Ishlarim · Profil»; модальные листы для входа, тарифов, фильтров.
- **API:** `https://govbot-web.vercel.app/api` (тот же прокси). Авторизация — JWT: access в памяти, refresh в `expo-secure-store` (backend отдаёт refresh в теле, когда нет заголовка `X-Auth-Cookie`). Ротация refresh, logout → blacklist.
- **Стриминг чата:** `fetch` из `expo/fetch` (поддерживает ReadableStream) + тот же SSE-парсер (`event: sources|status|done`).
- **Данные:** TanStack Query + персист в `expo-sqlite`/AsyncStorage → каталог и сценарии офлайн.
- **i18n:** те же ключи uz/ru/en, что на сайте (копия `frontend/src/i18n/*.json` + мобильные ключи).
- **Нативное:** expo-notifications (локальные напоминания), expo-speech (озвучка), распознавание речи (expo-speech-recognition), expo-haptics, Share API, expo-blur, Skia (girih, арка, анимированные орнаменты).

## Карта функций сайт → приложение

| Функция сайта | Экран приложения |
|---|---|
| Лендинг, поиск, вопрос в hero | **Bosh**: приветствие, поле вопроса + голос, «текущие дела», темы, роли |
| Каталог: категории, поиск, `?audience=` | **Katalog**: поиск, чипы категорий, фильтр аудитории (лист) |
| Сценарий: markdown, источник, verified, чек-лист, напоминание (.ics), «спросить ИИ», поделиться | **Сценарий**: те же блоки; напоминание = локальное уведомление |
| Чат: список бесед, новый, стриминг, стоп, источники, 👍/👎 + причина, простой язык, голос, озвучка, экспорт, связанные вопросы, «отвечено на …» | **Suhbat**: всё то же; экспорт = системный «Поделиться» |
| Мои чек-листы (локальный прогресс) | **Ishlarim**: сценарии в работе, прогресс, ближайшие напоминания |
| Вход / регистрация / выход | Лист входа (email + пароль; телефон/OneID — когда появятся на сервере) |
| Профиль: язык, имя, акцент, XL-шрифт, высокий контраст, экспорт данных, удаление аккаунта | **Profil**: всё то же + системный размер шрифта |
| Тарифы, лимиты (`/api/billing/*`, выключено) | Экран тарифов/лимита — показывается только при `billing_enabled` |
| Конфиг (`guest_chat`, `ai_mode` degraded) | Баннеры режима; гостевой чат — по флагу |
| О проекте, инструкция | Онбординг (3 экрана) + «Loyiha haqida» в профиле |
| Горячие линии 112/1173/1242 | Карточка «Yordam» в профиле + быстрый звонок |
| Admin (staff) | **Только веб** — инструмент редакторов, не функция гражданина |
| Конфиденциальность | Экран в профиле |
