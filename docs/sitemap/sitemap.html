Общая навигационная панель на всех страницах. Баннер офлайн-режима и PWA (manifest + service worker) работают поверх всего приложения.

Лендинг публично

/
  • Hero: слоган, кнопки «Спросить AI» и «Открыть каталог»
  • Features: AI-чат · каталог сценариев · три языка
  • Превью категорий: 7 карточек, ссылка /scenarios?category=slug

Вход публично

/login
  • email + пароль → JWT, редирект в /chat
  • ссылка на регистрацию

Регистрация публично

/register
  • имя, email, пароль → автоматический вход

404 публично

* (любой другой адрес)
  • страница «не найдено»

Каталог сценариев публично

/scenarios
  • сетка из 7 категорий, 35 сценариев в сидах
  • поиск и фильтр по категории (?category=)
  • контент на выбранном языке
▼ клик по карточке

Карточка сценария публично

/scenarios/:slug
  • markdown-текст инструкции
  • кнопка «Спросить AI об этом» → чат с готовым вопросом (гостя отправляет на вход)
  • Пробел: source_url здесь не показывается, ссылка на ведомство видна только в чипах чата

AI-чат нужен вход

/chat
  • сайдбар диалогов: создать, открыть, удалить
  • SSE-стриминг ответа, индикатор набора
  • RAG: ответы с чипами источников
  • 👍 / 👎 с причиной
  • похожие вопросы, быстрые подсказки
  • голосовой ввод (Web Speech)
  • экспорт диалога в Markdown
  • демо-режим без ключа OpenAI

Профиль нужен вход

/profile
  • имя, email, язык по умолчанию
  • Внешний вид: тема, акцентный цвет, размер шрифта, фон чата, сброс

Админ-панель staff

/admin

Семь вкладок:

1 · Пользователи
2 · Диалоги
3 · Категории
4 · Сценарии
5 · Аналитика
6 · Статистика

Что внутри
  • Пользователи: роль, блокировка, выдача админки, удаление
  • Диалоги: просмотр переписок
  • Категории и сценарии: CRUD, поля на 3 языках, публикация
  • Аналитика: топ вопросов, языки, пробелы каталога → «создать сценарий», 👎
  • Статистика: использование
  • Система: состояние сервиса
