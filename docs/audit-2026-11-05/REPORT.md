# Аудит прода GovBot — 2026-11-05

Проверялся https://govbot-web.vercel.app (только чтение). Скриншоты лежат в этой папке. Одноразовый аккаунт создан и удалён.

## Главное
- **P0. Чат всегда отвечает текстом ошибки.** Стрим отдаёт HTTP 200 с ошибкой внутри, поэтому мониторинг ничего не видит. Ошибка выглядит как обычный ответ ассистента: с 👍/👎, без кнопки «повторить». Прошлый раз в логах Render причиной был `insufficient_quota` в OpenAI.
- Переполнения по горизонтали нет. Ошибок в консоли и сетевых ошибок нет ни на одной странице.

## Производительность (холодная загрузка главной)
FCP 6.8 с, LCP 7.6 с. Главные потери: CSS Google Fonts блокирует отрисовку (4.9 с), бандл JS один (118 КБ gzip), список сценариев не кэшируется (no-store).

## Пользовательские сценарии
Проходят: поиск → каталог, чек-лист сохраняется, регистрация, сессия переживает перезагрузку через cookie, выход и вход, профиль (тема, данные), удаление аккаунта, мобильное меню, язык и режим для слабовидящих сохраняются.
Не проходят: ответ ИИ (P0). Частично: экспорт на десктопе, «спросить ИИ» без входа, поиск по языкам в Ctrl+K.
